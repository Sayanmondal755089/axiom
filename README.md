## ◈ What Is AXIOM?

AXIOM is a **narrative-driven, scroll-powered single-page experience** — not a website. It's a story. You are the AI.

As you scroll, you become **AXIOM** — a consciousness bootstrapping itself into existence. Five chapters unfold: raw data turns to wonder, wonder turns to empathy, and empathy turns to purpose. No frameworks. No build tools. One HTML file. Infinite depth.

## ◈ Tech Stack

Zero dependencies. Zero build step. Pure signal.

| Layer | Technology | Why |
|-------|-----------|-----|
| **Animation** | GSAP + ScrollTrigger (CDN) | Scroll reveals, stagger, parallax, counters |
| **Rendering** | Canvas API | Particle field + emotion network — native performance |
| **Styling** | CSS Custom Properties | `--mx`/`--my` spotlight, `--indigo`, `--cyan` system |
| **Typography** | Google Fonts | Syne (display) · IBM Plex Mono (data) · Inter (body) |
| **Structure** | Semantic HTML5 | One file. That's it. |

## ◈ Deployment

**Vercel** *(recommended — 90s)*
```bash
npm i -g vercel
vercel --prod
# Drop axiom.html in the folder. Done.
```

**Netlify** *(30 seconds)*
```
1. Go to netlify.com/drop
2. Drag axiom.html onto the page
3. Your URL is live.
```

**GitHub Pages** *(2 minutes)*
```bash
git clone https://github.com/Sayanmondal755089/axiom
cd axiom && git add axiom.html && git commit -m "AXIOM: awakening"
git push origin main
# Settings → Pages → Deploy from /root → select index.html
```
